# HOLLOW KIN

Realistic third-person survival horror in Unreal Engine 5.8 by Terratales Media Entertainment Private Limited.
Max Hunt goes fifteen floors down under St. Brigid's Clinic to bring his sister Emilia home.

**System requirements:** Mac — Apple M1, 8 GB, macOS 14 minimum; M2 Pro/M3 Pro+, 16 GB recommended. iPad — M1 minimum, M4 iPad Pro recommended. Details in [PLATFORMS §0](docs/PLATFORMS.md).
